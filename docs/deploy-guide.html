2. מה מקבלים

  • מוח אחד לשני בני הזוג — לא סשנים נפרדים
  • זיכרון, משימות, קניות, הערות, אירועים, מלאי, אנשים
  • המודל קורא/כותב דרך tools
  • Webhook ב-Railway / long-poll מקומי
חשוב: מנוי ChatGPT/Codex באפליקציה לא מספיק. צריך OpenAI API key עם billing פעיל. אפשר להגדיר OPENAI_MODEL למודל שזמין בחשבון (למשל gpt-4o).

3. הכנת סודות (~10 דקות)

1
צור בוט @BotFather → /newbot → שמור טוקן.
2
שני user IDs כל אחד כותב לבוט (או ל-@userinfobot). אחרי דיפלוי: /whoami → מכניסים ל-ALLOWED_USER_IDS.
3
מפתח OpenAI API keys + billing.

5. פריסה ב-Railway

1
פרויקט חדש railway.app/new → Deploy from GitHub → בחר shared-home-bot.
2
Volume Service → Volumes → Add → mount path: /data (חובה לזיכרון).
3
Variables הדבק את הבלוק מסעיף 6 (עם הערכים האמיתיים).
4
דומיין Settings → Networking → Generate domain. העתק ל-PUBLIC_URL (בלי / בסוף) → Redeploy.
5
Health פתח https://YOUR-DOMAIN/health → {"status":"ok"}.
כש-PUBLIC_URL מוגדר, הבוט רושם webhook אוטומטית ל-/telegram/webhook.

6. משתני סביבה

TELEGRAM_BOT_TOKEN=123456:ABC...
ALLOWED_USER_IDS=111111111,222222222
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o
DATABASE_PATH=/data/home.db
PUBLIC_URL=https://YOUR-SERVICE.up.railway.app
HOME_NAME=Our Home
BOT_DISPLAY_NAME=Home
משתנהחובההערה
TELEGRAM_BOT_TOKENכןBotFather
ALLOWED_USER_IDSכןשני השותפים, מופרד בפסיק
OPENAI_API_KEYכןAPI + billing
OPENAI_MODELלאברירת מחדל gpt-4o
DATABASE_PATHכן ב-Railway/data/home.db
PUBLIC_URLכן ב-RailwayHTTPS, בלי slash בסוף
OPENAI_BASE_URLלארק לפרוקסי תואם

9. הרצה מקומית

cd shared-home-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # מלא ערכים; PUBLIC_URL ריק
python -m app.main

PUBLIC_URL ריק = long polling (נוח לפיתוח).
